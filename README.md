# Frontend - Aplicación de Gestión de Transporte

## Descripción

Aplicación frontend construida con **React** y **Vite** que proporciona una interfaz completa para la gestión de transporte, cálculo de tarifas y administración de pasajeros.

## Características Principales

- **Autenticación**: Sistema de login seguro con rutas protegidas
- **Calculadora de Tarifas**: Herramienta interactiva para calcular precios de transporte
- **Gestión de Pasajeros**: Administración y visualización de información de pasajeros
- **Rutas Comerciales y Especiales**: Visualización de diferentes tipos de rutas disponibles
- **Historial**: Consulta del historial de transacciones y operaciones
- **Reportes**: Generación de reportes con exportación a Excel
- **Panel de Control**: Dashboard principal con información general
- **Contacto**: Formulario de contacto para consultas

## Tecnologías Utilizadas

- React 18
- Vite (bundler)
- React Router (navegación)
- ESLint (análisis de código)

## Estructura del Proyecto

```
src/
├── pages/           # Páginas principales de la aplicación
├── components/      # Componentes reutilizables
├── router/          # Configuración de rutas
├── config/          # Configuración de API
├── assets/css/      # Estilos CSS
└── utils/           # Funciones utilitarias
```
